## Where the differences come from

- Threshold: the top-hat disk. MATLAB uses `strel('disk', 42)` (N = 4 approximation, 5,877 px); skimage uses `disk(42, decomposition="sequence")`. With the top-hat off, the threshold masks are pixel-identical.
- Clean-up: image-border pixels only. `scipy.ndimage.binary_opening` erodes with `border_value=0`, so it trims 1 px off nuclei that touch the image edge; MATLAB `imopen` does not. About 40 px per image, no count changes.
- Watershed: MATLAB and skimage place the cut lines slightly differently (0.1% of pixels). Counts on the 3 images above are identical.
- None of these is an algorithm change, and all metrics are inside the allowed ranges, so the code was not changed.
